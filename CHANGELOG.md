# Catatan pembaruan

## 22 November 2026

- **Keuangan.** Gunakan tombol **+ Catat Keuangan** di atas halaman untuk mencatat pendapatan lain atau pengeluaran operasional. Dialog menampilkan pesan validasi dan menutup setelah transaksi tersimpan.
- **Tampilan.** Header lebih ringkas di Dashboard, Rental, Unit, Keuangan, dan Pengaturan. Aksi Dashboard, filter tanggal, dan KPI terlihat lebih awal. Tabel Unit dan Pengaturan lebih mudah digunakan di layar sempit.
- **Penyimpanan.** Armada, transaksi, tarif, dan pengaturan disimpan sebagai satu snapshot. Pemeriksaan revisi melindungi penulisan serentak antartab. Pesan kesalahan muncul jika browser gagal membaca atau menulis data.
- **Backup dan reset.** Impor memvalidasi file dan menampilkan pratinjau. Impor dan reset meminta unduhan salinan data saat ini sebelum konfirmasi. Aplikasi menolak pratinjau jika revisi data sudah berubah.

Setelah pembaruan, muat ulang semua tab aplikasi yang terbuka sebelum mencatat transaksi. Data tersimpan pada browser masing-masing. Simpan file backup di lokasi yang aksesnya terbatas karena file dapat memuat nama dan kontak pelanggan.
